# Mesurado AI Dashboard

An AI gateway and user dashboard for the Mesurado platform — lets users chat with the Mesurado LLM engine, manage API keys, track token usage, and handle payments.

## Run & Operate

| Service | Command | Port |
|---|---|---|
| API server | `pnpm --filter @workspace/api-server run dev` | 8080 |
| Dashboard (frontend) | `pnpm --filter @workspace/mesurado-dashboard run dev` | 22802 |

Other useful commands:
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)

### Required env / secrets

| Key | Type | Notes |
|---|---|---|
| `SESSION_SECRET` | secret | Cookie signing key — already set |
| `APPWRITE_API_KEY` | secret | Appwrite server-side API key — already set |
| `MESURADO_MASTER_TOKEN` | secret | Shared auth token for the AI engine — already set |
| `MESURADO_CORE_URL` | env var | AI inference server base URL — set to `https://ai.mediatechliberia.online` |
| `APPWRITE_ENDPOINT` | env var | Appwrite server URL — default `https://mediatechliberia.online/v1` |
| `APPWRITE_PROJECT_ID` | env var | Appwrite project ID — set to `mesurado01` |
| `APPWRITE_DATABASE_ID` | env var | Appwrite database ID — default `mesurado` |
| `DATABASE_URL` | runtime | Postgres connection string — runtime-managed by Replit |

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- **API:** Express 5, Pino logging
- **Frontend:** React 19, Vite, Tailwind CSS 4, Radix UI, TanStack Query, Wouter
- **Auth/backend services:** Appwrite (user accounts, sessions, database collections)
- **DB:** PostgreSQL + Drizzle ORM
- **Validation:** Zod (`zod/v4`), `drizzle-zod`
- **API codegen:** Orval (from OpenAPI spec in `lib/api-spec/`)
- **Build:** esbuild (bundled to `dist/index.mjs`)

## Architecture decisions

- **AI proxy pattern:** The API server (`/v1/chat/completions`) is a gateway that authenticates requests via Appwrite API keys, checks token balance, then forwards to the Mesurado Engine Core at `MESURADO_CORE_URL`. It never exposes the master token to clients.
- **Dual session auth:** Server sessions use an HMAC-signed cookie (`SESSION_SECRET`); the Appwrite browser SDK maintains its own session in parallel for client-side SDK calls.
- **`MESURADO_CORE_URL` is explicit:** The core URL is set as a named env var rather than derived from the deployment domain, because the inference engine is an independent service. Fallback to the gateway's own domain would cause a loopback.
- **Generated code is never edited:** `lib/api-client-react/` and `lib/api-zod/` are fully generated by Orval from the OpenAPI spec. Run `pnpm --filter @workspace/api-spec run codegen` after any spec change.

## Gotchas

- Run `pnpm install` from the workspace root before starting workflows on a fresh clone — `node_modules` are not committed.
- The API server build step (`pnpm run build`) compiles TypeScript via esbuild before `start`; the dev workflow runs both automatically.
- `APPWRITE_PROJECT_ID` must be set before auth or any Appwrite-backed route will work.
- `MESURADO_CORE_URL` (`https://ai.mediatechliberia.online`) is configured but not yet live — AI chat routes will return 502 until the inference server is running.
